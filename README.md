# Brain Signal AI

> AI-powered EEG signal analysis for intelligent brain disorder classification.

Brain Signal AI is an AI/ML-based project that analyzes EEG (Electroencephalogram) signals and applies machine learning and deep learning techniques to classify brain-related conditions.

The project combines signal processing, machine learning, deep learning, and embedded systems to create an end-to-end platform for EEG-based analysis.

## Features

* EEG signal analysis
* Signal preprocessing and feature extraction
* Machine learning-based classification
* XGBoost-based prediction
* Ensemble learning
* Transformer-based deep learning
* Flask-based API
* ESP32 integration
* Data visualization and analysis
* Web-based prediction workflow

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Brain-disorder.git
cd Brain-disorder
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## Running the Project

Start the backend/API:

```bash
python app.py
```

The API will run locally on:

```text
http://YOUR_LOCAL_IP:5000
```

Update the IP address and port according to your local network configuration.

## Machine Learning Pipeline

The project supports multiple approaches for EEG classification.

### XGBoost

XGBoost is used for efficient classification using extracted EEG features.

### Ensemble Learning

Multiple models can be combined to improve robustness and classification performance.

### Transformer Model

Transformer-based architecture can be used to learn complex patterns and temporal relationships within EEG signals.

## Data Processing

The general processing pipeline is:

1. Acquire EEG signals
2. Clean and preprocess the signals
3. Extract relevant features
4. Prepare the dataset
5. Train ML/DL models
6. Evaluate model performance
7. Generate predictions
